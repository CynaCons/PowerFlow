# v0.1.3 — Discipline skills

Brief produced with `powerflow-slice` on 2026-09-19 (its first run). Delete
this file when v0.1.3 closes and the SKILL.md files carry everything.

## Context

Owner (2026-09-18, accepting the proposal): *"PRD is once per project or when
changing major direction for a project. Then, whenever we work, PLAN.md comes
first - and last."* Both are decisions now (D10, D11) and shape three of the
five skills in this slice.

What exists: the four core-loop skills (`plan`, `slice`, `srs`, `verify`) and
`status` at `skills/powerflow-*/SKILL.md`; the SRS rows for the five to build
are `SRS-SKILL-002/003/008/009/010` in `docs/srs/SRS-skills.md`; the
templates they consume are `templates/docs/decisions/D-template.md` and
`templates/docs/agents/README.md`; `scripts/check.py` validates frontmatter,
size and presence. The sources each skill distils from
(`docs/proposal-2026-09-18.html` §6): PowerGit `AGENTS.md` "Engineering
rules" (owner reports), `PowerGit/.claude/skills/release/SKILL.md` and
`powerplan/docs/RELEASING.md` (release, including the 0.8.0 duplicate-dispatch
lesson), `PowerGit/docs/agents/README.md` (memories), RadEAU
`docs/decisions/` (ADRs), training deck F1 + D10 (PRD cadence).

Not the problem: the plan/verify mechanics — `powerflow-plan` and
`powerflow-verify` already own ticking, closing and evidence; the discipline
skills call them rather than restating them.

## Outcome

bug, decide, memory, release and prd exist as skills; a repo stamped by
`powerflow-init` can take an owner report through failing-test-first to
"awaiting owner verification", record a decision, write a memory, cut a
release with the ritual, and refuse a routine PRD edit — each with one
invocation.

## Requirements

- SRS-SKILL-008 — `powerflow-bug`: owner words verbatim, failing test before fix, task left open.
- SRS-SKILL-003 — `powerflow-decide`: D file with the reopening gate, README + PRD links.
- SRS-SKILL-010 — `powerflow-memory`: one fact per heading, dated, refusals.
- SRS-SKILL-009 — `powerflow-release`: refuse open iteration, single version source, check CI before dispatch.
- SRS-SKILL-002 — `powerflow-prd`: init or direction change only; redirects.
